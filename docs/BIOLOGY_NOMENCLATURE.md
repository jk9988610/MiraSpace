# MiraSpace 生物学命名与粒子表达

本文档说明：**画布上的简单粒子如何对应生物学概念**，以及各阶段、指标、未来扩展在生物学叙事中的名称。

> **重要**：下列命名是**类比与教学叙事**，不是真实分子结构或临床级模拟。代码内部仍使用 `monomer`、`strand` 等稳定标识符。

---

## 1. 设计原则

1. **简单粒子表达**：不画双螺旋或核糖体；用**不同颜色与大小的圆点/圆环/连线**表达实体。
2. **生物学命名**：界面、文档、直播弹幕优先使用生物学称谓（中英文对照见 `site/js/biology-names.js`）。
3. **涌现优先**：实体由场与局部规则产生，禁止脚本生成复制子、原细胞、群体（见 README 约束）。
4. **无固定原点**：世界周期边界（环面），平移可绕一圈回到同一景观。

---

## 2. 画布粒子（S1 前生物化学）

| 视觉 | 代码类型 | 生物学名称 | 大小（屏幕半径约） | 行为摘要 |
|------|----------|------------|-------------------|----------|
| 浅蓝小点 | `monomer` | **代谢单体** Metabolic monomer | 最大 ~5px | 被能量梯度牵引；酶附近可参与偶联 |
| 金黄点 | `catalyst` | **酶** Enzyme | ~7px | 移动慢；催化半径内两单体→二聚体 |
| 深蓝大点 | `dimer` | **生物大分子二聚体** Macromolecular dimer | ~8px | 可解离；局部富集驱动簇集 |

**场热力图**（控制按钮循环）：

| 模式 | 生物学含义 |
|------|------------|
| 热力·驱动 | 能量**梯度** — 代谢单体被拉向高能量区（趋能性） |
| 热力·能量 | **代谢场**能量浓度 |
| 热力·废物 | **代谢废物**堆积 — 增大运动阻力（类似胞内/外废物） |

## 3. 遗传聚合物（S2）

| 视觉 | 代码 | 生物学名称 | 说明 |
|------|------|------------|------|
| 紫边彩芯圆点 | `strand` | **核酸样聚合物** Polynucleotide strand | 可成核、模板复制、突变；色相表谱系（lineage） |
| 膜泡内小点 | `strand` + `vesicleId` | **胞内核酸** Cytosolic nucleic acid | 被原细胞膜泡封装 |

底层：`sequence[]` 为信息串（当前为 0/1 符号），对应**碱基对信息**的极简抽象，非真实 ATGC 绘制。

## 8. 未来扩展（终极愿景，未实现）

以下用生物学语言描述路线图，**当前版本未实现**：

| 生物学概念 | 计划实现方式（抽象） |
|------------|---------------------|
| 碱基对 / 双链 | 扩展 `sequence`  alphabet 与互补配对规则 |
| 剪辑、拼接 | 世界内**编辑酶**事件日志（cut/join/splice） |
| 染色体 | 聚合物束 + 拷贝数；分裂时**分配** |
| 有丝分裂 / 减数分裂 | 分裂算法 + 事件弹幕（无动画） |
| 基因表达 | 区段 ON → 改 chemoton/colony 参数 |
| 配子 / 受精 | 特化 vesicle + 基因组合并 → 受精卵 |

详见对话规格；实现时将延续「简单粒子 + 信息事件」而非分子动画。
